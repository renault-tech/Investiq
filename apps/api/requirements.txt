# Tetos de major version: sem eles, um build "frio" (sem lockfile — este
# requirements.txt não fixa patch/minor de propósito, ver comentário do
# topo do arquivo) resolve o que houver de mais novo no dia. Um pulo de
# major nessas duas SDKs (openai 1.x -> 3.x, google-genai 1.x -> 2.x)
# quase dobrou o peso de cada uma (openai: 11MB -> 6MB instalado,
# google-genai: 8.5MB -> 7MB) e sozinho foi o que estourou o limite de
# 225MB de função do Vercel num deploy sem nenhuma dependência nova —
# o código foi escrito e testado contra a API 1.x de ambas.
